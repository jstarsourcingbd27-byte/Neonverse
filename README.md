# NEONVERSE — 3D Anime Website

A futuristic 3D anime discovery landing page made with plain HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, the `css` folder, the `js` folder and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

## Notes
The demo poster images use external Unsplash image URLs. Replace them with your own images if you want a fully self-contained site.
